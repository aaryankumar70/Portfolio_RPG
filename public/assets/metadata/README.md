# Aryan's Adventure — Pixel Art RPG Asset Pack

Production-ready 16-bit cozy fantasy pixel-art RPG asset pack designed for 2D top-down game engines (Godot, Phaser 3, Unity, Tiled, PixiJS).

## Technical Specifications
- **Terrain Tile Size**: `32×32` pixels (PNG)
- **Character & NPC Frame Size**: `32×48` pixels per frame (transparent RGBA PNG)
- **Pet (Mango) Frame Size**: `32×32` pixels per frame (transparent RGBA PNG)
- **Buildings**: `128×96` and `96×128` pixels (multiples of 32-pixel world grid)
- **Scaling**: Nearest-Neighbor (`image-rendering: pixelated`)
